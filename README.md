Cars Hub

Cars Hub is a responsive automotive website for people who see cars as more than simple machines. The project celebrates automotive history, design, engineering, and performance through a selection of legendary Japanese and German vehicles.

Live Demo

Visit the published website: projectcar123.netlify.app

About the Project

This project was created to practise front-end development with HTML, CSS, and JavaScript. The homepage introduces the automotive theme, presents six featured vehicles, provides social-media and contact links, and includes an embedded documentary.

Each Read more button opens a dedicated details page containing the history and technical specifications of every featured car.

Responsive Design

The website uses a media query for screens up to 768px wide.

On smaller screens:

Vehicle cards are displayed in a single column

Images, tables, and videos adapt to the available width

Text and navigation elements become smaller

Main sections use reduced spacing

The embedded video keeps its 16:9 aspect ratio

Running the Project

Clone the repository:

git clone https://github.com/v1ctorx/Fake-Web-site-practicing-.git

Enter the project directory:

cd Fake-Web-site-practicing-

Open index.html in your browser. You can also run the project with the Live Server extension in Visual Studio Code.
